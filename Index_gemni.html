Architecture Overview

FADEC CLOSED-LOOP CONTROL SYSTEM

The forward control path commands the engine; the feedback path closes the loop by sampling thermodynamic state and returning verified inputs to the next cycle.

⌁
01 / Input

SENSORS

Samples exhaust gas temperature (EGT), rotor speeds (N1/N2), static pressure, and resolver angle.

▣
02 / Logic

FADEC (EEC)

Executes dual-channel voter logic, fuel scheduling, surge protection, and DO-178C control laws.

⚙
03 / Output

ACTUATOR

Translates digital command words into torque motor current, fuel metering valves, and guide vanes.

◉
04 / Plant

TURBINE ENGINE

Generates targeted thrust output while continuously shifting mechanical and thermodynamic states.

FEEDBACK & STATE VERIFICATION LOOP

Turbine telemetry is continuously sensed and returned to the EEC dual-channel voting stage at deterministic update rates.
